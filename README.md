# JT Sites — Site institucional

[![Site online](https://img.shields.io/badge/SITE-VER%20ONLINE-0EA5E9?style=for-the-badge&logo=githubpages&logoColor=white)](https://jtsites0.github.io/demo-site/)

Site institucional da **JT Sites**, iniciativa de desenvolvimento web focada na criação de sites profissionais, modernos e responsivos para pequenos negócios.

## 🌐 Site ao vivo

**https://jtsites0.github.io/demo-site/**

## Objetivo

Este repositório funciona como a primeira vitrine oficial da JT Sites. A página demonstra estrutura responsiva, identidade visual, interações em React, portfólio e captação de pedidos de orçamento.

## O que o site apresenta

- Apresentação da JT Sites
- Serviços oferecidos
- Processo de trabalho
- Portfólio inicial
- Princípios técnicos
- Formulário de orçamento
- Contato comercial
- Layout responsivo para celular, tablet e desktop

## Tecnologias

- HTML5
- CSS3
- JavaScript ES Modules
- React 19.2.8
- HTM 3.1.1
- GitHub Pages
- FormSubmit para encaminhamento do formulário

As bibliotecas executadas no navegador usam versões fixas. O site não depende de npm/Vite para ser publicado no GitHub Pages.

## Segurança

- Content Security Policy no documento
- bibliotecas com versões fixadas
- formulário com validação, limites de tamanho e honeypot
- requisição externa sem envio de credenciais/cookies
- timeout no envio do formulário
- links externos protegidos com `noopener noreferrer`
- nenhuma senha, token, API key ou segredo necessário no front-end
- política de divulgação responsável em `SECURITY.md`

## Princípios técnicos

- Código simples e organizado
- Responsividade desde o início
- Estrutura fácil de manter e adaptar
- Menor superfície de dependências possível para o modelo atual
- Identidade visual ajustável para diferentes projetos
