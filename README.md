# JT Sites — Projeto Demo

Projeto-base criado para demonstrar a construção de sites institucionais modernos e responsivos pela JT Sites.

A demonstração usa apenas HTML, CSS e JavaScript, mantendo a estrutura leve, fácil de entender e simples de adaptar para diferentes pequenos negócios.

## Estrutura

```text
demo-site/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── README.md
├── .gitignore
└── README.md
```

## Características

- Layout responsivo
- Navegação adaptada para dispositivos móveis
- Seções reutilizáveis
- HTML semântico
- CSS organizado com variáveis
- JavaScript simples e sem dependências
- Estrutura preparada para personalização

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador ou utilize um servidor local de sua preferência.

## Personalização

Textos, cores, serviços e informações de contato foram centralizados em uma estrutura simples para facilitar a adaptação do projeto a futuros clientes.
