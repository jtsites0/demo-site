# Security Policy

## Supported version

The version published from the `main` branch and GitHub Pages is the supported version of this project.

## Contact

For security-related reports, contact JT Sites privately at **jtsites.contato@gmail.com**.

Please include a clear description, reproduction steps when available, expected impact, and the browser or device used.

Avoid posting sensitive technical details in a public issue before the report has been reviewed.

## Scope

This is a static website hosted on GitHub Pages. It has no login system, first-party database, or client-side credential storage. Quote form messages are sent through the external FormSubmit service.

This project does not currently operate a paid bug bounty program.
